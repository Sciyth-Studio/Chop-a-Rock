# Weather

Plan: `WeatherSystemPlan.md` (approved 2026-10-14, W1-W12). Rules: Master Game Plan §05. Every number is a draft in `WeatherConfig`.

## Rules
- **Clock:** `WeatherClock` (shared, pure). Slot `k` starts at `k * 1800` Unix seconds and lasts 900 s. The event for a slot is a weighted roll seeded by `ClockSeed + k`, so every server agrees without talking. Weights: Sandstorm 35, Hurricane 25, Heat Wave 20, Thunderstorm 15, Eclipse 5.
- **Rocks:** while an event is on, every per-player rock (Rush rocks too) pays the event's `RockMultiplier` (`WeatherService:ApplyRockMultiplier`, right after `Rush.ApplyPayout` in RockService). The Diamond Rock is not boosted.
- **Catching:** once a minute during an event, each placed Rok of each player in the server has `CatchChance` (2%) to catch the modifier, if it beats the one it has. Offline players catch nothing.
- **Hatching:** a geode cracked during an event has `HatchChance` (25%) to hatch with the modifier (`WeatherService:RollHatchModifier` → `PetService:Grant(..., modifier)` → `GeodeHatched` carries it).
- **Value:** `RokModifier.Rate` = base $/s × multiplier. Used by pedestal earnings, offline income, Equip Best, tooltips and `RokValue.Sell`.

## Where things live
- Shared: `Config/WeatherConfig` (events, looks, modifiers, texts, attribute names), `WeatherClock`, `RokModifier` (Get, Multiplier, Rate, Name "Zappy Bloky", Tint, IsBetter), `NumberFormat.Rate` (one decimal under 1,000, so x1.5 rates read "$1.5/s").
- Server: `WeatherService` ticks every second and publishes Workspace attributes `Weather` (key or ""), `WeatherStartedAt`, `WeatherEndsAt`, `NextWeatherAt` (server time). It sends the 1-minute warning, start and end notices. Every weather notice (those three and the catch notice) uses the kind `Weather_<Modifier>` (`NoticeKindPrefix`; `NotificationConfig` registers one per modifier), and the `Notifications` screen gives those a top-to-bottom `LabelTop`→`LabelBottom` text gradient and a dark stroke (user asked 2026-10-14). Admin overrides: `Force(key)`, `EndActive()`, `StartIn(seconds)`; an ended or overridden natural slot is suppressed until its own end.
- Data: `Pet.Modifier` (already in the schema). `PetService:SetModifier(player, petId, modifier, isCatch)` writes it, re-syncs tools, fires `ModifierChanged` (PedestalService refreshes and re-banks the rate), and notifies "Bloky caught Zappy! $1/s → $3/s".
- Display: the pedestal and `PlacedRok` carry the `Modifier` attribute; a modified `PlacedRok` or Rok tool is tagged `ModifiedRok`. A change on a kept `PlacedRok` sets `ModifierCaughtAt` (server time), which plays the catch effect.
- Client: `WeatherController` tweens `Lighting`, `Atmosphere` and `ColorCorrection` toward the event's `Look` over 4 s and back to the values captured at start, parents the camera rig (`VFX_Weather_<Event>`, a slab of emitters that follows the camera; Low Graphics turns its emitters off), loops the event sound (skipped while the SoundId is empty), adds the modifier emitters (named `WeatherVFX`) to every `ChopRock`-tagged rock, and runs lightning (flash on its own `WeatherFlash` ColorCorrection, `VFX_Weather_Lightning`, thunder) in a Thunderstorm. The Eclipse rig has a `Sun` part with a dark disc + corona billboard kept in the sun's direction.
- `Components/ModifiedRok`: modifier emitters (named `ModifierVFX`) on the main part, the tint for Toasty/Eclipsed (eyes skipped), the catch burst `VFX_Catch_<Modifier>` when `ModifierCaughtAt` is fresh.
- UI: `StarterGui.WeatherPill` is a mirror of the HUD money row in the bottom-right corner (user asked 2026-10-14): icon with 8 outline copies and a shadow on the right, right-aligned italic text, black backdrop fading to the left. ## Gotchas
- Rain streaks need a negative `Squash` (-3) with `VelocityParallel`; positive Squash made the 2026-10-14 rain fall as sideways dashes.
- Rocks get particles only, no tint: Rush paints the rock gold and fades back to its own saved colour, so a tint would fight it.
- The skybox is a texture, so the sky colour only shifts through Atmosphere and ColorCorrection; the Eclipse sky still reads bluish.
