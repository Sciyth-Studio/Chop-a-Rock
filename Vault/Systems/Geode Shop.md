# Geode Shop

Decided 2026-10-14 (user): geodes are bought from the one lobby Geode Shop, with a tab per zone like the [[Index]], not from a stand in each zone. It opens on the highest zone whose geode `StrengthRequired` the player meets (Forest below that).

- GUI: `StarterGui.GeodeStand.Panel`, widened to 944 for a `Tabs` column on the left (copied from the Index tabs; `TabTemplate` with `Label` = zone, `Count` = "<n> Strength"). The grid and buy buttons moved 92 px right; `GeodeStandConfig.ButtonCenterOffsetPixels` keeps the buy buttons centred under the grid. Active tab Sky blue, idle grey (`GeodeStandConfig.Palette.TabActive/TabIdle`).
- Code: `GeodeStand.luau` builds one tab per geode in `Order`; `Open` ignores the pad's `ScreenKey` and picks `GeodeOrder.ForStrength`. Tabs for zones the player can't reach still show the odds, with the "Need X Strength" blocker.
- `Utils/GeodeOrder`: `Sorted()` (by `Order`) and `ForStrength(strength)`. Admin "Grant Rok" and "+1 Geode" use the same pick, so they follow the player's strength.
- Adding a zone: `PetConfig` Roks, a `GeodeConfig.Geodes.<Zone>` entry with `TabName` and `Order`, the geode models, and the `IndexConfig` Roks zone. No new stand.
- Desert (2026-10-14): Desert Geode $40,000, 2,500 Strength, `Model_Geode_Desert` / `Model_GeodeSplit_Desert` (the Basic models with the shell 220, 140, 40; crystals unchanged). Odds 57.5 / 25 / 11 / 5 / 1.35 / 0.15 (Claude's draft between forest and jungle; the shop shows Ankhy as 1.4%). Income forest x80.

## Pity (built 2026-10-22, playtested by the user the same day)
Plan and decisions: `GeodePitySystemPlan.md`; numbers from [[Balance Model]] v9.
- **Rules:** two counters per geode, saved in `PlayerData.Pity[geodeKey] = { Legendary, Secret }` (misses since the last hit at that rarity or better), kept through rebirth. Thresholds in `GeodeConfig.Geodes.<Zone>.Pity` at 2x expected hatches: Legendary 165 / 110 / 75 / 50 / 35, Secret 1,830 / 1,120 / 780 / 360 / 270 (Forest → Snow). The crack that reaches a threshold is guaranteed; Secret is checked first (`GeodeConfig.PityRarities`). A guaranteed Legendary is always the geode's Legendary, never its Secret (`HatchOdds.RollRarity`). Geode Fall hatches don't touch the counters; weather modifiers still roll on a guaranteed hatch. Admin "Next Hatch" counts like a real crack.
- **Code:** `HatchPity` (shared: `Threshold`, `Due`, `After`, `Left`); `GeodeService/Cracking.Release` rolls the guarantee and writes the counters right after the grant, with no yield; `GeodeHatched` has a last `IsPity` field (Geode Fall sends false).
- **UI (Studio, save the place):** `GeodeStand.PopRoot.Panel.Pity` holds `Legendary` and `Secret` bars (dark body, 3px black stroke, `Fill` sized by progress, Chrome `Label` + `LabelShadow`) at x 208, y 98, 510x46, left of `LuckToggle`. Code paints Legendary's fill from its rarity colour and Secret's with the rainbow, and writes "Legendary in 37" (`GeodeStandConfig.PityFormat`). `HatchReveal.Content.Body.Pity` is a Gold "Guaranteed!" stamp (a `NewBadge` copy at x -205, rotated -14), shown when `IsPity`.
- **Admin:** "Pity: Next Due" (Roks tab, alias `pity`, choice Legendary / Secret) sets the zone geode's counter to one short of its threshold.
- **Checked by value in Edit 2026-10-22:** `Due` fires at 164 Forest misses and not 163; Secret wins when both are due; `After` resets the right counters; `RollRarity` Legendary gives only Berry / Ankhy / Tiki / Glowy / Climby; 20,000 simulated Forest cracks at luck 1 never passed 164 misses (45 guarantees, Legendary+ 1.32% vs 1.1% base). `check.ps1` passes. The user then playtested a pity crack in Play ("works now", 2026-10-22), after the Rojo sync fix in [[Studio Live Editing vs Rojo]].

## Choosing which geode to crack (built 2026-10-28, not playtested)
Testers asked to choose the geode; the user picked a picker panel with a saved choice.
- **Rule:** `GeodeOrder.Pick(geodes, selected)` (shared, used by `Cracking.PickGeode` and the picker) cracks `PlayerData.SelectedGeode` while you own one, otherwise the old order (Lucky first, then highest zone). Auto-open follows it too.
- **Pit:** a second owned prompt `PickPrompt` ("Choose Geode", F / ButtonY, no hold) on a `GeodePickSpot` attachment `GeodeConfig.PickPromptOffset` above `GeodeSpot`, tagged `GeodePickPrompt`. Shown only when you own 2+ geode kinds and aren't cracking.
- **Panel:** `StarterGui.GeodePicker` (Studio copy of `GiftPicker` minus Players/Empty/Back, title "Geodes", Lucky Geode header icon; `ItemTemplate.Card.Preview` ViewportFrame added over the icon). `Screens/GeodePicker.luau` opens on the prompt, one card per owned geode (zone Sky, Lucky Gold, "x3" ribbon, Choose / Chosen), click sends `SelectGeode` (server checks you own it) and closes. Texts in `GeodePickerConfig`. Save the place for the new ScreenGui.
