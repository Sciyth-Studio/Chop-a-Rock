Six in-world leaderboard boards the user shared as inspiration for [[To Do]]'s Leaderboards item. Nothing is decided yet; this is what to take from each.

**Signpost list.** A tall blue stud signpost with a big lime "Most Money/s" title. Each row is a white card with an avatar headshot, the name and a green "Money/s:" pill above the value. The list scrolls. Take: avatar headshots and the stat pill on every row.
![[Leaderboard Ref Money Sign.webp]]

**Ranked table (three boards, one frame).** The same dark framed board with neon side pillars is reused for Venom, Playtime and Robux Spent. It has an icon in the header, `# / Player / Stat` columns, gold, silver and bronze rows for the top 3, alternating purple and dark rows below them, and lime values. A pinned "#100+ You" row at the bottom shows your own value. Take: one frame reused per stat, top-3 medal colours, the pinned "You" row.
![[Leaderboard Ref Table Venom.webp]]
![[Leaderboard Ref Table Playtime.png]]
![[Leaderboard Ref Table Robux.webp]]

**Stone arch.** A stone gateway built in the world's own block style. Each row has `#1`, a headshot, the name and the value. Take: a frame built from the game's own world pieces. The dog and "0 Appeal" along the bottom are that game's HUD caught in the screenshot, not part of the board.
