# Boulder reference

![[Boulder Reference.webp]]

What to take from it, for the boulder remodel of the chop rocks ([[Rocks Look Like Boulders]]):

- **Shape:** one rounded, chunky boulder per rock, wider than tall, with a flat base. Big flat facets (low-poly, roughly 20 to 40 visible faces), no stacked blocks.
- **Shading:** flat-shaded facets; each facet reads as its own plane.
- **Colour:** mid grey, with some facets warm tan/brown. The paper-like surface grain in the image is not wanted unless the user asks.
- **Studs:** the user wants studs on top of this look (not in the image).
