## Shared traits
- **Header bar**: solid saturated color per panel (orange, salmon-red), subtle brick/stud texture, big white title with thick dark stroke, value in yellow beside it.
- **Close button**: square red button with white bold X, dark outline, top-right, overlapping the header edge.
- **Body**: dark translucent green panel, studded texture, thick dark border, rounded corners.
- **Buttons**: chunky rounded rectangles, saturated fill, dark outline, white stroked text; disabled = grey. Premium action is purple with the Robux icon.
- **Text**: heavy rounded font, white with dark stroke; keywords colored inline ("Cash Multi" green, warning text red).
- **Progress bar**: dark track, green fill, text centred over it.
- **Icons**: chunky 3D-ish icons (cash stack, arrows) used next to values.
- **Index cards**: unknown entries show a black silhouette with "???"; tooltip on hover with name and income.

## Copy / ignore
- Copy: the **layout and content** — what's on the panel, where, and in what order (2026-10-02).
- Don't copy: the visual style (rounded corners, solid header bars, green body). Restyle with [[Menu Panel Style]].
