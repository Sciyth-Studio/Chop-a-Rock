# Literal black and grey

Said 2026-10-10 about the base remodel: "use actual black and actual grey unless stated otherwise."

- Black is near-neutral black (about 20,20,20; pure 0,0,0 hides the stud overlay). Grey is neutral (R = G = B), around 128 for light stone and 90 for darker stone.
- Don't tint toward slate, blue-grey or warm grey to make up for the lobby lighting. The old base was tinted warm on purpose (see [[Why The Game Looks Blue]]), and that's no longer the default. If the lighting shifts it, raise that with the user rather than tinting.
- Reference sheets also tint (the Gemini sheet showed slate). Take colours from what the user says, not from the sheet.
