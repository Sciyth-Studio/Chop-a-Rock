# Keep decor simple

The user (2026-10-14) wants zone decoration as simple and as few pieces as possible. How detailed a model Claude can make in Blender depends on how much usage the user is willing to spend, and decoration doesn't affect the fun of the core chop loop.

How to apply:
- Suggest props made of a few basic shapes (boxes, cylinders, cones, spheres), not detailed set pieces like ruins, shipwrecks or cabins.
- Model one shape and recolour it for several zones (a pine becomes a snowy pine), and reuse meshes the game already has (rock meshes, the Diamond Rock crystals).
- Anything Studio parts can make well enough (fences, crates, lantern posts) stays in Studio, with no Blender model.
- Particles and lighting give each zone its feel for free, so lean on them.
