# Event timer icons: ChatGPT prompts (2026-11-09)

The event timers in the bottom-right corner show one icon per upcoming event with a countdown under it (vault: Event Timer Icons Reference). All five weather events already have icons. These three are missing.

How to run: in ChatGPT image generation, attach `IconReferenceSheet.png` (this folder) and paste one prompt per chat. Ask for a transparent PNG. Save the results here as `GeodeFall.png`, `DiamondRock.png` and `BossFist.png`, and Claude will clean them up and upload them through Open Cloud.

The sheet is eight icons the game already uses: thunderstorm, cloud, hurricane, cracked egg, rocket, flame, clover and crown.

---

```
Make one new game icon in exactly the same style as the attached icon sheet: flat-colour chunky 3D cartoon shapes, a slightly darker side face for depth, small white highlight slivers, bright saturated colours, no outline, no text, no background. Match the line weight, shading and level of detail of the sheet; it must sit next to those icons as part of the same set.

Subject: a falling meteor egg. A chunky speckled egg, purple with a few small glowing purple crystal chips stuck in its shell, flying diagonally down toward the bottom right. Behind it, a big curved fire trail streaming up to the top left in two layers: hot pink-red outside and orange-yellow inside, shaped like the flame icon on the sheet. Keep it readable as a small icon: one egg, one trail, nothing else.

Square 1:1 image, the icon centred and filling about 85% of the frame, fully transparent background, no shadow on the ground, no glow halo around the edges.
```
